# Development journal

This is a chronological trail of how Gnarlaxx was made. Add an entry at a
meaningful checkpoint, using `NNNN_short_description_YYYYMMDD.md`: a four-digit
sequence number, a descriptive slug, and the date of the work. Use the actual
session date; the initial entries are from 2026-10-04.

Record the context, decisions and reasons, concrete changes, validation results,
and what remains. Include useful commit references without duplicating every
command. Keep earlier entries as history; later decisions belong in new entries.
Update this index when adding an entry. Continue making small, meaningful Git
commits alongside the journal.
